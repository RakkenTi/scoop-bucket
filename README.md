# RakkenTi Scoop Bucket

[Scoop](https://scoop.sh) bucket for tools published by
[RakkenTi](https://github.com/RakkenTi).

## Apps

- [mdre](https://github.com/RakkenTi/mdre) - a terminal markdown (GFM) manager.

## Usage

```powershell
scoop bucket add rakkenti https://github.com/RakkenTi/scoop-bucket
scoop install mdre
```
